# Getting help

| You have… | Go to |
| --- | --- |
| A question about installing or using the plugin | [GitHub Discussions](https://github.com/soumendudas22/dsh-turn-timeline/discussions) if they are enabled; otherwise [open an issue](https://github.com/soumendudas22/dsh-turn-timeline/issues/new) and add the `question` label. |
| A bug | The [bug report form](https://github.com/soumendudas22/dsh-turn-timeline/issues/new?template=bug_report.yml). |
| An idea or feature request | The [feature request form](https://github.com/soumendudas22/dsh-turn-timeline/issues/new?template=feature_request.yml). |
| A security vulnerability | Do not open a public issue. Follow [SECURITY.md](SECURITY.md). |
| A problem with DeepSeek Harness itself | The [DeepSeek Harness repository](https://github.com/deepseek-ai/deepseek-harness/issues). |

Whatever the channel, include your DeepSeek Harness (DSH) version and the plugin version — it makes answers much faster.
